# Reports and exports

Choose a session in Reports, give it a title and reproduction steps, then create
the report. Download HTML for an offline, self-contained timeline and JSON
evidence. Reports include version, configuration, observed trends, limitations
and finalized capture integrity when available. User text is escaped; there are
no executable report scripts or external assets.

Redaction defaults to removing process paths/host identity and process keys from
report configuration. Operation labels and reproduction text are user supplied;
do not include business IDs or secrets. Raw .lscap exports retain process metadata
and require separate privacy review before sharing. Raw exports require a
finalized session and are unavailable after raw-capture retention expires.
