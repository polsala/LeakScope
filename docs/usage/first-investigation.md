# First investigation

Sign in, open Processes and filter by executable or PID. Inspect its parent,
resident memory and version path evidence. Version path evidence is not an ABI
fingerprint. Use Diagnose and the three-step wizard to choose a purpose, the
available depth and conservative duration/cadence. Unsupported modes are disabled.

Recording appears only after sensor confirmation. RSS and intermittent PSS are
different measurements; an unavailable PSS value is not zero. Add a baseline
marker, carry out the intended operation yourself, then mark cooldown. Pause
visualization freezes the view while capture continues. Stop Capture ends the
lease. Finalized metrics, quality, capture export and reports remain available.

Read the evidence panel before acting on growth. The interface never infers a
Python source line, allocation stack or object owner from RSS alone.
