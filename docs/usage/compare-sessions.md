# Compare intervals or sessions

On a recorded session choose Compare the two halves to compare equal elapsed
time intervals within that capture. The comparison uses OS RSS observations,
sample counts and resistant slopes. It does not invent allocated/freed totals.

On Comparisons select two captured sessions and create a stored comparison.
Review sample counts and coverage warnings. Different workloads, durations,
worker roles, cold caches and garbage-collection timing can confound results.
Repeat the same controlled operation and include cooldown before claiming a fix.
