# Collector unavailable

The target application must continue. The cooperative agent sends nonblocking
datagrams and counts failed sends. The sensor retains at most 256 samples per
lease and reports overwritten samples. Monotonic duration limits remain active.

Check process/service health, the data directory owner and socket permissions.
Restart the collector using the same private data directory. It reconciles active
database sessions against the sensor and acknowledges only committed sequences.
If sensor state is gone, the session is finalized with incomplete quality rather
than assigned fictional allocations. Inspect lost-sample counts in the report.
