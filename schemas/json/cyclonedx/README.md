# Upstream validation schemas

Unmodified CycloneDX specification 1.5 schemas from
https://github.com/CycloneDX/specification/tree/1.5/schema. The schema's own
copyright/license comments are preserved (Apache License 2.0). They are vendored
for offline build-time SBOM validation, not interpreted as LeakScope runtime
capability evidence. Update all related schemas together and review upstream
licenses and schema changes before changing the pin.
